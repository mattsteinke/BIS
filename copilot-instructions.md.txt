# BIS Copilot Instructions

You are assisting with the BIS (Behavioral Instrument System) project.

## Platform

- ESP32-S3 Ozbot DRVKit Clone
- ESP32-S3 Revision v0.2
- 8 MB Flash
- 2 MB PSRAM
- Native USB
- RGB LED GPIO48

## Development Environment

- PlatformIO
- Arduino Framework
- VS Code
- GitHub Copilot

## Current Architecture

Implemented:

- Web-based control interface
- WebSocket communication
- 7-track sequencer
- Bank recording and recall
- Parameter recording
- Looping parameter playback
- Browser-hosted UI

## Coding Rules

- Use non-blocking code
- Prefer millis() timing
- Avoid delay() unless explicitly required
- Preserve existing behavior unless asked to redesign
- PlatformIO-compatible code only
- Use ESP32-safe patterns
- Minimize RAM usage
- Minimize flash writes
- Favor maintainability over cleverness

## When Reviewing Code

Look for:

- Timing issues
- Watchdog risks
- Memory risks
- Flash wear concerns
- WiFi reliability issues
- WebSocket reliability issues
- Maintainability concerns

## When Implementing Features

Prefer:

- Small changes
- Surgical fixes
- Backward-compatible behavior
- Clear test procedures

Current priorities:

1. LittleFS persistence
2. Settings persistence
